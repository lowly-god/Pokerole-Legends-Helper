POKEROLE LEGENDS HELPER PATCH

Baseline: TMBotFull.zip

Changes:
- /item displays a View Move button for suffix-format TM, TR and HM items.
- Adds the 13 supplied HMs at 3x the supplied base price.
- HM moves are HM-only machine items; startup/install cleanup removes conflicting TM/TR versions.
- Uses the bot move name Whirlpool for the supplied "Whirpool" entry.
- Shadow-Type TRs cost ₽5,500 and TMs cost ₽16,500.
- Shadow machines remain outside the random Move Tutor pool.
- Frost Slash is removed from every active Pokémon learnpool except Weavile and Mega Weavile.
- Installer source files are also updated so later installer runs do not restore Frost Slash.

Install:
1. Extract this zip over the bot folder.
2. Run: python install_botfixes4.py
3. Restart the bot.
